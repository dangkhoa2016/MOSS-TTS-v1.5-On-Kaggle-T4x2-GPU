# Pronunciation control

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](pronunciation-control.vi.md)

MOSS-TTS v1.5 natively supports IPA spans. The project does not silently rewrite user text. Reviewer-facing examples may use readable casing such as `Moss` or explicit IPA for technical tokens such as BF16, and must label that behavior as pronunciation control.
