# Engineering overview

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](engineering-overview.vi.md)

This project keeps the original BF16 MOSS-TTS-v1.5 checkpoint and solves deployment on Kaggle T4 x2 through explicit module placement and staged codec decode. It intentionally does not present itself as a general-purpose TTS serving framework.
