# Điều khiển phát âm

> 🌐 Language / Ngôn ngữ: [English](pronunciation-control.md) | **Tiếng Việt**

MOSS-TTS v1.5 hỗ trợ native IPA spans. Dự án không âm thầm rewrite text người dùng. Ví dụ cho reviewer có thể dùng casing dễ đọc như `Moss` hoặc IPA tường minh cho token kỹ thuật như BF16 và phải ghi rõ đây là pronunciation control.
